# Перенос механики оружия из Game1 в GameBlock

Источник: [vivab/Game1](https://github.com/vivab/Game1), только чтение. Оригинальные файлы Game1 не изменены.

## Что перенесено
- Настоящая система `makeHand` из `Game1/hands.js`: сегменты пальцев, отдельный большой палец, варианты хвата `pistol`, `cup`, `fist`, `open`.
- Анимационные ключи `KF`, `DRAW`, `FROM`, `KICK`, интерполяция `sample` из `Game1/hands.js`: доставание, осмотр, перезарядка, рывок при выстреле, осмотр/удар ножом.
- Формула разброса `SPREAD` из `Game1/game.js` с накоплением отклонения и восстановлением точности.

## Что НЕ перенесено
- Карта `lowpoly__fps__tdm__game__map_by_resoforge.glb` из Game1.
- Оружие и другие GLB-файлы Game1.
- Сетевой код, боты и картографический движок Game1 (существующий матч GameBlock 5 на 5 сохранён).

## Какие GLB используются
Исключительно существующие файлы GameBlock:
- `public/models/g18.glb`
- `public/models/ak47.glb`
- `public/models/knife_ct.glb`
- `public/models/knife_t.glb`

## Подгонка хвата на телефоне
Значок ⚙ → выбери оружие → «Оружие», «Правая рука» или «Левая рука».
Для рук можно менять X/Y/Z, углы кистей, сгибание пальцев и тип хвата.
Настройки хранятся локально в браузере под `gameblock:game1-grip-v1`. 
Кнопка «Копировать координаты» выводит JSON, который можно прислать для фиксации по умолчанию.
